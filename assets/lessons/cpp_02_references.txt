@title Pass by Reference

In C, a function gets a copy of each ordinary argument (pass by value), and the only way to change the caller's variable is to pass a pointer. C++ adds a third option: pass by reference.

With pass by reference, the function does not get a copy. The parameter is the caller's actual variable under a different name, so any change the function makes is a change to the original. You write it with & in the parameter list.

```
void tryToChange(int &x) {  // note the & : pass by reference
    x = 999;                // changes the caller's variable
}
```

Now if you call tryToChange(value), value really does become 999.

# Value versus reference, side by side

```
#include <iostream>
using namespace std;

// Pass by value: works on a copy
void addOneByValue(int x) {
    x = x + 1;
    cout << "Inside addOneByValue: x = " << x << endl;
}

// Pass by reference: works on the original
void addOneByReference(int &x) {
    x = x + 1;
    cout << "Inside addOneByReference: x = " << x << endl;
}

int main() {
    int a = 5;
    cout << "a before: a = " << a << endl;
    addOneByValue(a);
    cout << "After addOneByValue: a = " << a << endl;
    addOneByReference(a);
    cout << "After addOneByReference: a = " << a << endl;
    return 0;
}
```

Output:

```
a before: a = 5
Inside addOneByValue: x = 6
After addOneByValue: a = 5
Inside addOneByReference: x = 6
After addOneByReference: a = 6
```

# Why use pass by reference?

- To modify the caller's variable. A swap(int &a, int &b) can exchange two variables, which is impossible with pass by value.
- To avoid copying large data. Passing a big object by value copies the whole thing; passing by reference avoids that cost.
- To return more than one value. A function returns one value, but it can change several reference parameters.

# Comparison

- What is passed: by value, a copy of the value; by reference, a reference to the original variable.
- Syntax: void f(int x) for value; void f(int &x) for reference.
- Can the function change the caller's variable? By value: no. By reference: yes.
- Typical use: by value when the function only reads the value; by reference to modify the caller's variable or avoid copying large data.

# Reference versus pointer

Pass by reference and pass by pointer do very similar jobs. Here are both versions of swap in one program. C++ allows two functions with the same name as long as their parameters differ, so the call decides which one runs.

```
#include <iostream>
using namespace std;

void swap(int *x, int *y) {   // pass by pointer
    int z = *x; *x = *y; *y = z;
}

void swap(int &x, int &y) {   // pass by reference
    int z = x; x = y; y = z;
}

int main() {
    int a = 45, b = 35;
    cout << "Before Swap a=" << a << " b=" << b << "\n";
    swap(&a, &b);
    cout << "After pointer swap a=" << a << " b=" << b << "\n";
    swap(a, b);
    cout << "After reference swap a=" << a << " b=" << b << "\n";
    return 0;
}
```

Output:

```
Before Swap a=45 b=35
After pointer swap a=35 b=45
After reference swap a=45 b=35
```

Both swaps worked: the second one swapped the values back.

- Pass by reference is seen as neater code: no & at the call and no * inside the function.
- Pass by pointer can pass a null pointer (nullptr); a reference must always refer to a real variable.
- Use pass by reference when you don't need "nothing" as an option.
- When a function only reads a reference parameter, make it const, for example void print(const string &s).

> A reference must be initialised when it is created, and it can never be changed to refer to a different variable. Assigning to it changes the original instead.

@solution
```
#include <iostream>
using namespace std;

void doubleIt(int &x) {
    x = x * 2;
}

int main() {
    int n = 5;
    doubleIt(n);
    cout << "n = " << n << endl;
    return 0;
}
```
! With int x the function gets a copy of n. With int &x, x is a reference, another name for n itself, so the change is seen in main. The call doubleIt(n) stays the same.
