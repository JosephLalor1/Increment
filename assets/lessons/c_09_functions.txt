@title Functions

Functions break a big program into small, named pieces. Each function has a return type, a name, a list of parameters, and a body.

```
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

void printGreeting() {
    printf("Hello! Welcome to C programming.\n");
}

double calculateAverage(int arr[], int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += arr[i];
    }
    return (double)sum / size;
}

int main() {
    int sum = add(5, 3);
    printf("5 + 3 = %d\n", sum);

    printGreeting();

    int scores[] = {85, 90, 78, 92, 88};
    int size = sizeof(scores) / sizeof(scores[0]);
    double avg = calculateAverage(scores, size);
    printf("Average score: %.2f\n", avg);

    // Functions can be called many times
    printf("10 + 20 = %d\n", add(10, 20));
    return 0;
}
```

Output:

```
5 + 3 = 8
Hello! Welcome to C programming.
Average score: 86.60
10 + 20 = 30
```

- int add(int a, int b) returns an int and takes two int parameters
- void means a function returns nothing, like printGreeting
- return sends a value back to the caller and ends the function

# Function prototypes

The compiler reads the file from top to bottom, so a function must be declared before it is called. If you want to write main first, put a prototype at the top. A prototype is the first line of the function followed by a semicolon:

```
int add(int a, int b);   // prototype: defined later
```

# Passing arrays to functions

When you pass an array to a function, the function does not get its own copy. It works directly on the caller's array, so any change it makes is visible back in main.

```
#include <stdio.h>

void doubleAll(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2;  // changes the original array
    }
}

int main() {
    int numbers[] = {1, 2, 3, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);

    doubleAll(numbers, size);

    for (int i = 0; i < size; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n");
    return 0;
}
```

Output:

```
2 4 6 8 10
```

> Inside a function, sizeof(arr) does not give the array's size: the function only receives where the array starts. That is why the size is passed as a separate parameter.

# Pass by value

Ordinary variables such as int, double and char are passed by value: the function gets a copy. Whatever it does to its parameter has no effect on the caller's variable.

```
#include <stdio.h>

void tryToChange(int x) {
    x = 999;  // only changes the local copy
    printf("Inside function: x = %d\n", x);
}

int main() {
    int value = 5;
    printf("Before call: value = %d\n", value);
    tryToChange(value);
    printf("After call:  value = %d\n", value);
    return 0;
}
```

Output:

```
Before call: value = 5
Inside function: x = 999
After call:  value = 5
```

That is why add(5, 3) is safe: add gets copies and cannot accidentally change anything in main.

> To let a function change the caller's variable, C passes its address with a pointer (coming up in the pointers lessons). C++ also has pass by reference with &, covered in the C++ track.

```
#include <stdio.h>

int max(int a, int b);  // prototype: max is defined below main

int main() {
    printf("max(3, 9) = %d\n", max(3, 9));
    printf("max(12, -4) = %d\n", max(12, -4));
```

```
int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```
