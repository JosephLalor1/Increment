@title From C to C++

C++ grew out of C. Almost everything you learned in the C track still works, but C++ adds its own features: references, classes, new and delete, and a new way of doing input and output.

```
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}
```

Output:

```
Hello, C++!
```

# What changed from C?

- #include <iostream> replaces <stdio.h>. It provides cout for output and cin for input.
- cout << "text" sends text to the screen. The << operator can be chained to print several things in a row.
- endl ends the line, like "\n".
- using namespace std; lets you write cout instead of std::cout. Without it, you need the std:: prefix every time.
- C++ files usually end in .cpp, and you compile them with g++ instead of gcc (or as a C++ project in Visual Studio).

# Printing values

cout works out the type of each value for you, so there are no format specifiers like %d.

```
#include <iostream>
using namespace std;

int main() {
    int apples = 3;
    double price = 0.5;
    char grade = 'A';
    cout << "I have " << apples << " apples" << endl;
    cout << "Price: " << price << ", grade " << grade << endl;
    return 0;
}
```

Output:

```
I have 3 apples
Price: 0.5, grade A
```

> cout prints doubles in their shortest form: 3.0 prints as 3 and 0.50 prints as 0.5. You will see this in the lesson outputs from here on.

# Reading input

cin >> reads a value into a variable. There is no & to remember: C++ handles that for you.

```
#include <iostream>
using namespace std;

int main() {
    int age;
    // stdin: 25
    cout << "Enter your age: " << endl;
    cin >> age;
    cout << "Next year you will be " << age + 1 << endl;
    return 0;
}
```

Output:

```
Enter your age:
Next year you will be 26
```

# Namespaces

The std:: prefix says that cout lives in the std namespace, where the standard library keeps all its names. Namespaces stop names from different libraries clashing. using namespace std; brings all of those names into your program so you can drop the prefix.

@solution
```
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age = 0;
    cout << "Name and age: ";
    cin >> name >> age;
    cout << "Hi " << name << ", next year you will be "
         << age + 1 << endl;
    return 0;
}
```
! Each >> reads the next value from the input into a variable of the right type: the word into the string, then the number into the int. (The prompt "Name and age: " is printed on the same line, so the output starts with it.)
