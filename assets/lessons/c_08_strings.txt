@title Strings and the Null Terminator

C has no separate string type. A string is just an array of characters, and the only thing that makes it a string is that it ends with a special character called the null terminator, written '\0'.

When you write:

```
char name[20] = "Alice";
```

the array holds 'A', 'l', 'i', 'c', 'e', '\0', then unused space up to index 19. The compiler adds the '\0' for you when you use a string literal in double quotes.

If you build the array character by character, you have to add the '\0' yourself:

```
char city[30] = {'N', 'e', 'w', ' ', 'Y', 'o', 'r', 'k', '\0'};
```

Forget it, and it is not a string, just an array of characters. printf("%s") would then keep reading past the end into random memory until it happened to hit a zero byte.

# Why the null terminator matters

Every %s in printf works the same way: start at index 0, print character after character, and stop at '\0'. That is the entire mechanism. There is no length stored anywhere; the '\0' is the length marker.

# Doing it manually

To find the length of a string, start at index 0 and count until you reach '\0':

```
#include <stdio.h>

int main() {
    char name[20] = "Alice";

    int len = 0;
    while (name[len] != '\0') {
        len++;
    }

    printf("%s has %d characters\n", name, len);
    printf("The array holds %d bytes\n", (int)sizeof(name));
    return 0;
}
```

Output:

```
Alice has 5 characters
The array holds 20 bytes
```

The length (5) and the size of the array (20) are different things. The array has room for 19 characters plus the terminator.

> '\0' is the character with value 0. It is not the same as '0', the digit zero, which has value 48.

# Changing characters

A string in a char array can be changed one character at a time, like any other array:

```
#include <stdio.h>

int main() {
    char word[] = "cat";
    word[0] = 'b';
    printf("%s\n", word);

    word[2] = '\0';  // end the string early
    printf("%s\n", word);
    return 0;
}
```

Output:

```
bat
ba
```

? What marks the end of a string in C?

- The last element of the array

- A newline character
! C strings have no stored length; printf and friends stop when they reach '\0'.

? How many chars of the array does "Alice" use, including the terminator?
- 5
* 6
- 20
- 4
! 5 letters plus the '\0' the compiler adds.

? What is wrong here?
```
char s[3] = {'H', 'i', '!'};
printf("%s", s);
```
- Nothing, it prints Hi!
* There is no '\0', so printf reads past the end of the array
- %s cannot print char arrays
- The array is too big
! Without a terminator printf keeps reading into whatever memory follows.

? What does this print?
```
char w[] = "hello";
w[1] = 'a';
printf("%s", w);
```
- hello
* hallo
- aello
- ha
! Index 1 is the second character, 'e', which becomes 'a'.

? What does this print?
```
char w[] = "planet";
w[4] = '\0';
printf("%s", w);
```
- planet
- plane
* plan
- et
! printf stops at the first '\0', which is now at index 4.

? Which is true about '\0' and '0'?
- They are the same character
* '\0' has value 0; '0' is the digit character with value 48
- '\0' is a newline
- '0' ends a string
! Only the character with value 0 terminates a string.

?code This loop should replace every 'a' in the string with '*', but it stops partway through. Make it go all the way to the end of the string.
@hint The loop always stops at 5, whatever the string's length.
@hint Keep going until text[i] is the null terminator, '\0'.
```
#include <stdio.h>

int main() {
    char text[] = "banana bandana";
    for (int i = 0; i < 5; i++) {
        if (text[i] == 'a') {
            text[i] = '*';
        }
    }
    printf("%s\n", text);
    return 0;
}
```
@expect
```
b*n*n* b*nd*n*
```
@solution
```
#include <stdio.h>

int main() {
    char text[] = "banana bandana";
    for (int i = 0; text[i] != '\0'; i++) {
        if (text[i] == 'a') {
            text[i] = '*';
        }
    }
    printf("%s\n", text);
    return 0;
}
```
! A C string ends at its null terminator, so text[i] != '\0' visits every character whatever the length. (strlen(text) from <string.h> would work as well.)
