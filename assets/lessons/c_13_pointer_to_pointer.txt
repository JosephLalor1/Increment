@title Pointers to Pointers

A pointer is a variable, so it has an address too. A pointer to a pointer stores the address of another pointer. This is called double indirection.

```
int i = 5;
int *ptr = &i;     // ptr points to i
int **pptr = &ptr; // pptr points to ptr
```

- pptr holds the address of ptr
- *pptr is the value of ptr, which is the address of i
- **pptr follows both links and gives i itself

# An illustration

Trace each line. The comments show what changes.

```
#include <stdio.h>

int main() {
    int i = 5, j = 10;
    int *ptr;
    int **pptr;   // pointer to pointer to int
    ptr = &i;
    pptr = &ptr;  // pptr holds the address of ptr
    *ptr = 3;     // i = 3
    **pptr = 7;   // i = 7 (through both pointers)
    ptr = &j;     // ptr now points to j
    **pptr = 9;   // j = 9: pptr still leads to ptr
    *pptr = &i;   // changes ptr itself: back to i
    *ptr = -2;    // i = -2
    printf("i = %d, j = %d\n", i, j);
    return 0;
}
```

Output:

```
i = -2, j = 9
```

The key line is **pptr = 9. pptr never changed, but ptr did, so following the chain now lands on j. And *pptr = &i changes ptr without ever naming it.

Step through it and watch the two arrows. Click pptr at any step to see what *pptr and **pptr are.

# Why you need them

To let a function change the caller's int, you pass an int *. In the same way, to let a function change the caller's pointer, you pass a pointer to that pointer, an int **. You will use this when building linked lists, where a function has to change the head pointer.

```
#include <stdio.h>

void pointAt(int **pp, int *target) {
    *pp = target;   // changes the caller's pointer
}

int main() {
    int a = 1, b = 2;
    int *p = &a;
    pointAt(&p, &b);
    printf("*p = %d\n", *p);
    return 0;
}
```

Output:

```
*p = 2
```
