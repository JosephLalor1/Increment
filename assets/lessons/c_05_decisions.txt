@step
~ 1 conditions:1
```
#include <stdio.h>

int main() {
    int number = 23;
    if (number >= 90) {
        printf("Number is greater than 90\n");
    }
    return 0;
}
```
@expect
```
Number is less than 90
```
@solution
```
#include <stdio.h>

int main() {
    int number = 23;
    if (number >= 90) {
        printf("Number is greater than 90\n");
    }
    else {
        printf("Number is less than 90\n");
    }
    return 0;
}
```
