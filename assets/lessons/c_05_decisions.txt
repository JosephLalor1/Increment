@title Decisions: if, else and switch

Programs make decisions with if. The condition in brackets is checked; if it is true, the block runs. else if adds more conditions, checked in order, and else catches everything that did not match.

```
#include <stdio.h>

int main() {
    int score = 23;

    if (score >= 90) {
        printf("Grade: A - Excellent!\n");
    }
    else if (score >= 80) {
        printf("Grade: B - Good!\n");
    }
    else if (score >= 70) {
        printf("Grade: C - Satisfactory\n");
    }
    else if (score >= 60) {
        printf("Grade: D - Needs improvement\n");
    }
    else {
        printf("Grade: F - Failed\n");
    }
    return 0;
}
```

Output:

```
Grade: F - Failed
```

Only the first matching branch runs. A score of 95 is also >= 80, but it stops at the A branch.

> In C, 0 counts as false and any other value counts as true.

# Comparison and logical operators

- == equal, != not equal, <, >, <=, >= compare values
- && means AND: true only if both sides are true
- || means OR: true if either side is true
- ! means NOT: flips true and false

```
#include <stdio.h>

int main() {
    int age = 10;

    if (age >= 18 && age <= 65) {
        printf("You are of working age.\n");
    }
    else if (age < 18 || age > 65) {
        printf("You are not of working age.\n");
    }
    return 0;
}
```

Output:

```
You are not of working age.
```

> Watch out: = assigns and == compares. if (x = 5) stores 5 in x and is always true.

# The switch statement

switch checks one variable against several specific values. Each case is a possible value. break ends the switch; without it, execution falls through into the next case. default runs if no case matched.

```
#include <stdio.h>

int main() {
    char grade;
    // stdin: b
    printf("Enter your grade (A, B, C, D, F): \n");
    scanf(" %c", &grade);

    switch (grade) {
        case 'A':
        case 'a':
            printf("Excellent performance!\n");
            break;
        case 'B':
        case 'b':
            printf("Good job!\n");
            break;
        case 'C':
        case 'c':
            printf("Satisfactory\n");
            break;
        default:
            printf("Invalid grade entered\n");
    }
    return 0;
}
```

Output:

```
Enter your grade (A, B, C, D, F):
Good job!
```

Stacking case 'B': and case 'b': with nothing between them uses fall-through on purpose: both values run the same code.

@hint 85 >= 50 is true, so the Distinction test is never reached. Test the higher mark first.
```

int main() {
    int score;

        printf("Pass\n");

        printf("Distinction\n");
    } else {
        printf("Fail\n");

}

#include <stdio.h>

int main() {
    int score;
    scanf("%d", &score);
    if (score >= 80) {
        printf("Distinction\n");
    } else if (score >= 50) {
        printf("Pass\n");
    } else {
        printf("Fail\n");
    }
    return 0;
}
```
! Only the first true branch of an if / else if chain runs. Every score of 80 or more is also 50 or more, so the stricter test has to come first.
