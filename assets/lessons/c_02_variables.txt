@title Variables and Data Types

A variable is a named piece of memory that holds a value. Unlike some languages, C makes you declare the type of every variable before you use it. The type decides what values it can hold and how much memory it takes.

```
#include <stdio.h>

int main() {
    // Integer types
    int age = 25;           // whole numbers (typically 4 bytes)
    short small = 100;      // smaller integer
    long big = 1000000L;    // larger integer

    // Decimal numbers
    float price = 19.99f;   // single precision (4 bytes)
    double pi = 3.14159;    // double precision (8 bytes)

    // Character
    char grade = 'A';       // a single character in single quotes

    printf("Age: %d\n", age);
    printf("Price: %.2f\n", price);  // .2 shows 2 decimal places
    printf("Grade: %c\n", grade);
    printf("Pi: %f\n", pi);
    return 0;
}
```

Output:

```
Age: 25
Price: 19.99
Grade: A
Pi: 3.141590
```

# Format specifiers

printf uses placeholders that are replaced by the values that follow:

- %d prints an int
- %f prints a float or double (6 decimal places by default)
- %c prints a single char
- %s prints a string
- %.2f prints a float or double with exactly 2 decimal places

# Uninitialised variables

If you declare a variable without giving it a value, it is not set to zero. It holds whatever value happened to be in that memory already.

```
int var;   // not initialised: holds a leftover value
```

> Always give a variable a value before you read it. Reading an uninitialised variable is a classic source of bugs that only appear sometimes.

# Literal suffixes

19.99f has an f on the end to mark it as a float. Without it, 19.99 is a double. 1000000L uses L to mark a long.

# Constants

Put const in front of a declaration to make the variable unchangeable. Trying to assign to it later is a compile error.

```
#include <stdio.h>

int main() {
    const double TAX_RATE = 0.08;
    const int MAX_SCORE = 100;

    // TAX_RATE = 0.10;  // this would cause an error!

    printf("Tax rate: %.2f\n", TAX_RATE);
    printf("Max score: %d\n", MAX_SCORE);
    return 0;
}
```

Output:

```
Tax rate: 0.08
Max score: 100
```

@solution
```
#include <stdio.h>

int main() {
    int quantity = 3;
    double price = 4.5;

    printf("Quantity: %d\n", quantity);
    printf("Total: %.2f\n", quantity * price);
    return 0;
}
```
! The format specifier has to match the type: %d for an int, %f for a double. The .2 in %.2f rounds the printed value to 2 decimal places.
