@title Constructors, Pointers to Objects and this

Manually initialising your fields gets tedious:

```
Vector vec;
vec.start.x = 0.0; vec.start.y = 0.0;
vec.end.x = 0.0;   vec.end.y = 0.0;
```

Can we initialise them when we create an instance? Yes, with a constructor.

# Constructors

A constructor is a method that is called when an instance is created. It has the same name as the class and no return type.

```
#include <iostream>
using namespace std;

class Point {
public:
    double x, y;
    Point() {
        x = 0.0; y = 0.0;
        cout << "Point instance created" << endl;
    }
};

int main() {
    Point p;  // the constructor runs here
    cout << p.x << " " << p.y << endl;
    return 0;
}
```

Output:

```
Point instance created
0 0
```

# Parameters and multiple constructors

Constructors can accept parameters, and a class can have several constructors as long as their parameters differ. The one that runs depends on how you create the instance.

```
#include <iostream>
using namespace std;

class Point {
public:
    double x, y;
    Point() {
        x = 0.0; y = 0.0;
        cout << "default constructor" << endl;
    }
    Point(double nx, double ny) {
        x = nx; y = ny;
        cout << "2-parameter constructor" << endl;
    }
};

int main() {
    Point p;            // default constructor
    Point q(2.0, 3.0);  // 2-parameter constructor
    cout << "q is (" << q.x << "," << q.y << ")" << endl;
    return 0;
}
```

Output:

```
default constructor
2-parameter constructor
q is (2,3)
```

> A constructor with no parameters is called the default constructor. Note that it is Point p; and not Point p(); because the brackets would declare a function.

# Initialisation lists

Fields can be initialised in an initialisation list, after a colon and before the constructor's body. You can use either round brackets or curly braces:

```
class Point {
public:
    double x, y;
    Point() : x(0), y(0) {
    }
    Point(double nx, double ny) : x(nx), y{ny} {
    }
};
```

# Using a pointer to an object

A pointer to an object works like any other pointer. Declaring a pointer does not create an instance. Use -> to reach the members of the instance it points to.

```
#include <iostream>
using namespace std;

class Point {
public:
    double x, y;
    Point() : x(0), y(0) {}
};

int main() {
    Point *pPtr;  // pointer to Point: no instance yet
    Point p;
    pPtr = &p;
    pPtr->x = 10;  // through the pointer
    p.y = 20;      // directly
    cout << p.x << " " << p.y << endl;
    cout << pPtr->x << " " << pPtr->y << endl;
    return 0;
}
```

Output:

```
10 20
10 20
```

Both lines print the same values: pPtr and p refer to the same instance.

# Using new to create an instance

new creates an instance on the heap and returns a pointer to it. The constructor still runs. Use -> to access members, and delete the instance when you are done.

```
#include <iostream>
using namespace std;

class Point {
public:
    double x, y;
    Point() {
        x = 0.0; y = 0.0;
        cout << "Point instance created" << endl;
    }
};

int main() {
    Point *p = new Point();  // instance created; p points to it
    Point *pPtr = p;         // a second pointer, same instance
    pPtr->x = 10;
    p->y = 20;
    cout << p->x << " " << p->y << endl;
    delete p;                // one delete for one new
    return 0;
}
```

Output:

```
Point instance created
10 20
```

> With a pointer, p.x does not compile: p is a pointer, not a Point. You need p->x.

# The this pointer

Inside a method, this is a pointer to the instance the method was called on. this->x is the same as plain x. It is useful when a parameter has the same name as a field:

```
class Point {
public:
    double x, y;
    Point(double x, double y) {
        this->x = x;  // field x = parameter x
        this->y = y;
    }
};
```

?code The constructor's parameters have the same names as the fields, so the point stays at (0, 0). Fix the constructor with the this pointer.
@hint Inside the constructor, x means the parameter, not the field.
@hint this->x is the field x of the object being constructed.
```
#include <iostream>
using namespace std;

class Point {
public:
    double x = 0;
    double y = 0;
    Point(double x, double y) {
        x = x;
        y = y;
    }
};

int main() {
    Point p(1, 2);
    cout << "(" << p.x << ", " << p.y << ")" << endl;
    return 0;
}
```
@expect
```
(1, 2)
```
@solution
```
#include <iostream>
using namespace std;

class Point {
public:
    double x = 0;
    double y = 0;
    Point(double x, double y) {
        this->x = x;
        this->y = y;
    }
};

int main() {
    Point p(1, 2);
    cout << "(" << p.x << ", " << p.y << ")" << endl;
    return 0;
}
```
! A parameter hides a field with the same name, so x = x just assigns the parameter to itself. this points at the object being built, so this->x reaches the field. (An initialisation list, : x(x), y(y), would also work.)
