@title Pass by Pointer

In the Functions lesson you saw that C passes ordinary variables by value: the function gets a copy, so it cannot change the caller's variable. Pointers solve this. If you pass the address of a variable, the function can reach the original through it.

# Value versus pointer

```
#include <stdio.h>

void f(int j) {
    j = 5;        // changes the copy only
}

void g(int *ptr) {
    *ptr = 5;     // changes the caller's variable
}

int main() {
    int i = 3;
    f(i);
    printf("after f(i):  i = %d\n", i);
    g(&i);
    printf("after g(&i): i = %d\n", i);
    return 0;
}
```

Output:

```
after f(i):  i = 3
after g(&i): i = 5
```

- f(i) passes a copy of the value 3. Changing j has no effect on i.
- g(&i) passes the address of i. Inside g, ptr holds that address, so *ptr = 5 changes i itself.

Step through both calls and watch each function's stack frame appear and disappear:

```memory
title A copy versus an address
> int i = 3;
var i int 3
say main has one variable, i, holding 3.
> f(i);          // f gets a copy of i
frame f
var j int i
say Calling f(i) copies the value 3 into f's own variable j. j lives in f's stack frame at a different address from i, so the two are not connected.
> j = 5;         // changes the copy only
set j 5
say Changing j changes f's copy. i in main is still 3.
> }              // f returns
return
say When f returns, its frame and j disappear. i was never touched, so it is still 3.
> g(&i);         // g gets the address of i
frame g
var ptr int* &i
say Calling g(&i) passes the address of i. g's parameter ptr holds that address, so its arrow reaches out of g's frame and into main's.
> *ptr = 5;      // changes the caller's variable
set *ptr 5
say *ptr follows the arrow out of g and into main, so i becomes 5. This is how a function changes its caller's variable.
> }              // g returns
return
say g returns and ptr disappears, but the change made through the pointer stays: i is 5.
```

# Incrementing through a pointer

```
#include <stdio.h>

void increment(int *numPtr) {
    (*numPtr)++;  // dereference, then increment
}

int main() {
    int x = 5;
    increment(&x);  // pass the address of x
    printf("x = %d\n", x);
    return 0;
}
```

Output:

```
x = 6
```

> The brackets in (*numPtr)++ matter. *numPtr++ would move the pointer itself forward and leave x unchanged.

# Swapping two variables

A swap function is the classic case: it must change both of the caller's variables, which is impossible with pass by value.

```
#include <stdio.h>

void swap_ints(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 5, y = 10;
    swap_ints(&x, &y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
```

Output:

```
x = 10, y = 5
```

```memory
title Inside swap_ints
> int x = 5, y = 10;
var x int 5
var y int 10
say main's two variables, x and y.
> swap_ints(&x, &y);
frame swap_ints
var a int* &x
var b int* &y
say The call passes two addresses. Inside swap_ints, a points to x and b points to y.
> int temp = *a;
var temp int *a
say temp is a plain int. *a follows a's arrow to x, so temp gets a copy of x's value, 5.
> *a = *b;
set *a *b
say *b follows b's arrow to y and reads 10. Storing it in *a puts 10 into x.
> *b = temp;
set *b temp
say Storing temp in *b puts 5 into y. The two values have swapped.
> }              // swap_ints returns
return
say swap_ints returns, and a, b and temp disappear with its frame. x and y keep their swapped values: x = 10, y = 5.
```

# Returning more than one value

A function can only return one value, but it can fill in as many results as you give it pointers for. scanf works exactly like this, which is why it needs &.

```
#include <stdio.h>

void minMax(int arr[], int size, int *min, int *max) {
    *min = arr[0];
    *max = arr[0];
    for (int i = 1; i < size; i++) {
        if (arr[i] < *min) *min = arr[i];
        if (arr[i] > *max) *max = arr[i];
    }
}

int main() {
    int data[] = {7, 2, 9, 4};
    int lo, hi;
    minMax(data, 4, &lo, &hi);
    printf("min %d, max %d\n", lo, hi);
    return 0;
}
```

Output:

```
min 2, max 9
```

@hint Use *a and *b, and make temp an int.

@expect
```

```
@solution
```
#include <stdio.h>

void swap_ints(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 3, y = 7;
    swap_ints(&x, &y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
```
! The pointers themselves are passed by value, so swapping a and b only swaps the function's copies. Swapping *a and *b changes the ints they point at, which are main's x and y.
