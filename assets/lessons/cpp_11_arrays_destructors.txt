# Arrays of objects

An array can hold objects just like ints. Every element is constructed when the array is created, so the class needs a default constructor (one that takes no arguments).

```
#include <iostream>

class Point {
public:
    int x;
    Point() {}
    Point(int val) : x(val) {}
    void Print() {
        std::cout << x;
    }
};

int main() {
    Point points[20];  // 20 default-constructed Points
    for (int i = 0; i < 20; i++) {
        points[i].x = i;
    }
    for (int i = 0; i < 20; i++) {
        points[i].Print();
    }
    std::cout << std::endl;
    return 0;
}
```

Output:

```
012345678910111213141516171819
```

# Using new to create the array

new Point[30] creates an array of 30 Points on the heap. Free it with delete[].

```
Point *points = new Point[30];
for (int i = 0; i < 30; i++) {
    points[i].x = i;
}
delete[] points;
```

# Arrays of pointers

Instead of an array of objects, you can have an array of pointers, where each pointer points to an object created with new. Use -> on each element, and delete every object you created.

```
#include <iostream>

class Point {
public:
    int x;
    Point(int val) : x(val) {}
    void Print() { std::cout << x << " "; }
};

int main() {
    Point *pointPointers[5];
    for (int i = 0; i < 5; i++) {
        pointPointers[i] = new Point(i * 10);
    }
    for (int i = 0; i < 5; i++) {
        pointPointers[i]->Print();
    }
    std::cout << std::endl;
    for (int i = 0; i < 5; i++) {
        delete pointPointers[i];
    }
    return 0;
}
```

Output:

```
0 10 20 30 40
```

Each Point here can be built with its own constructor arguments, so no default constructor is needed.

The array of pointers can itself be allocated with new. Its type is then Point **, a pointer to the first of many Point pointers:

```
Point **pointPointers = new Point*[30];
for (int i = 0; i < 30; i++) {
    pointPointers[i] = new Point(i);
}
// ... use them ...
for (int i = 0; i < 30; i++) {
    delete pointPointers[i];  // each Point
}
delete[] pointPointers;       // then the array
```

# Destructors

A destructor is a method that is called when an object is destroyed: when it goes out of scope, or when it is deleted. It is written ~ClassName(), with no return type and no parameters. Its job is to clean up, usually by freeing memory the object allocated.

```
#include <iostream>
using namespace std;

class Noisy {
public:
    int id;
    Noisy(int i) : id(i) { cout << "construct " << id << endl; }
    ~Noisy() { cout << "destruct " << id << endl; }
};

int main() {
    Noisy a(1);
    {
        Noisy b(2);
    }  // b goes out of scope here
    cout << "inner block done" << endl;
    Noisy *c = new Noisy(3);
    delete c;  // the destructor runs on delete
    return 0;
}  // a goes out of scope here
```

Output:

```
construct 1
construct 2
destruct 2
inner block done
construct 3
destruct 3
destruct 1
```

# Why destructors matter

This class allocates 20,000 Points in its constructor and frees them in its destructor:

```
class Point {
public:
    int x, y;
};

class TwentyThousandPoints {
public:
    Point *points;
    TwentyThousandPoints() {
        points = new Point[20000];
    }
    ~TwentyThousandPoints() {
        delete[] points;
    }
};
```

The lecture creates 10,000 of these inside a block, then keeps the program running:

```
{
    TwentyThousandPoints points[10000];
}
// the block has ended: do the destructors run?
```

That is 10,000 x 20,000 Points of 8 bytes each, about 1.6 GB. Watching the process memory in Visual Studio's diagnostic tools shows the difference:

- Without the destructor, memory climbs to about 1.7 GB and stays there after the block ends: every array has leaked.
- With the destructor, memory spikes and then drops back down as each object is destroyed at the end of the block.

@solution
```
#include <iostream>
using namespace std;

class Noisy {
public:
    int id;
    Noisy(int i) {
        id = i;
        cout << "made " << id << endl;
    }
    ~Noisy() {
        cout << "destroyed " << id << endl;
    }
};

int main() {
    Noisy *items[3];
    for (int i = 0; i < 3; i++) {
        items[i] = new Noisy(i + 1);
    }
    cout << "using them" << endl;
    for (int i = 0; i < 3; i++) {
        delete items[i];
    }
    return 0;
}
```
! The array holds pointers, and the objects they point at live on the heap. delete runs each object's destructor and then frees its memory; without it the objects leak and their destructors never run.
