@title Your First C Program

C is a procedural language: a program is a list of instructions that run one after another, and execution always starts at a function called main(). Every statement ends with a semicolon ;, and blocks of code are wrapped in curly braces { }.

C is a compiled language. A compiler turns your source code into machine code before the program runs. Here is the classic first program:

```
#include <stdio.h>  // gives us input/output functions

int main() {
    printf("Hello, World!\n");
    return 0;  // 0 means "everything worked correctly"
}
```

Output:

```
Hello, World!
```

# Line by line

- #include <stdio.h> pulls in the standard input/output header, which declares printf.
- int main() is where execution starts. The int means main gives back a whole number when it finishes.
- printf("Hello, World!\n"); prints the text in quotes. \n is the newline character.
- return 0; ends main and tells the operating system the program succeeded.

> Forgetting a semicolon is the most common first error. The compiler usually reports it on the line after the one that is missing it.

# Compiling and running

With gcc, you compile and run from a terminal like this. In Visual Studio, building the project does the same job.

```
gcc hello.c -o hello
./hello
```

# Reserved words

C has a small set of keywords that are reserved by the language. You cannot use them as variable or function names. They fall into groups:

- Data types (9): int, char, float, double, void, short, long, signed, unsigned
- Control flow (11): if, else, switch, case, default, for, while, do, break, continue, return
- Storage class (4): auto, register, static, extern
- User-defined types (4): struct, union, enum, typedef
- Qualifiers (4): const, volatile, restrict (added in C99), _Atomic (added in C11)
- The special operator sizeof, which gives the size of a type or variable in bytes

> You will also see goto listed as a keyword. It exists, but it is almost never used in modern code.

?code This program should print its two messages on two separate lines, but they come out joined together. Fix it.
@hint printf only starts a new line where you ask it to.
@hint The escape sequence for a new line is \n.
```
#include <stdio.h>

int main() {
    printf("Hello, World!");
    printf("Welcome to C.\n");
    return 0;
}
```
@expect
```
Hello, World!
Welcome to C.
```
@solution
```
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    printf("Welcome to C.\n");
    return 0;
}
```
! printf prints exactly the characters you give it. Without \n at the end of the first message, the second one carries on along the same line.
