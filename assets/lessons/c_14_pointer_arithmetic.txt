@title Pointer Arithmetic and Arrays

You can add to and subtract from a pointer to move it through memory:

- ptr + 1 is the next memory location of that type
- ptr - 1 is the previous one
- ptr * 2 and ptr / 2 are invalid: multiplying or dividing an address means nothing

# Walking through an array

Trace this code. ptr starts in the middle of the array and moves both ways.

```
#include <stdio.h>

int main() {
    float a[4] = {0, 0, 0, 0};
    float *ptr;
    ptr = &(a[2]);  // ptr points to a[2]
    *ptr = 3.14;    // a[2] = 3.14
    ptr++;          // now points to a[3]
    *ptr = 9.0;     // a[3] = 9.0
    ptr = ptr - 3;  // back to a[0]
    *ptr = 6.0;     // a[0] = 6.0
    ptr += 2;       // forward to a[2]
    *ptr = 7.0;     // a[2] = 7.0

    for (int i = 0; i < 4; i++) {
        printf("a[%d] = %.2f\n", i, a[i]);
    }
    return 0;
}
```

Output:

```
a[0] = 6.00
a[1] = 0.00
a[2] = 7.00
a[3] = 9.00
```

# Arrays and pointers

In most expressions an array name stands for the address of its first element. So a is the same as &a[0], and these are all equivalent:

- a[2] is the same as *(a + 2)
- ptr = &(a[2]) is the same as ptr = &(*(a + 2)), which is ptr = a + 2

The difference is that a is a constant address (you cannot write a++), while ptr is a pointer variable you can move.

# Steps are sized by type

ptr + 1 does not add 1 byte. It adds the size of one element, so the pointer lands on the next element whatever its type. A double usually takes 8 bytes, so for double *ptr = a; with a at address 1000, ptr + 1 is 1008.

```
#include <stdio.h>

int main() {
    double a[3] = {37.9, 1.23, 3.14};
    double *ptr = a;
    char *start = (char *)ptr;
    char *next = (char *)(ptr + 1);

    printf("bytes between elements: %d\n", (int)(next - start));
    printf("*(ptr + 1) = %.2f\n", *(ptr + 1));
    return 0;
}
```

Output:

```
bytes between elements: 8
*(ptr + 1) = 1.23
```

# Exercises

Using pointer arithmetic only, with no a[i] indexing:

```
#include <stdio.h>

// Returns the sum of numValues values starting at ptr
int sum(int *ptr, int numValues) {
    int total = 0;
    for (int *end = ptr + numValues; ptr < end; ptr++) {
        total += *ptr;
    }
    return total;
}

int main() {
    int arr[] = {4, 6, 7, 8, 9};

    // 1. Output the 5 integers
    for (int *p = arr; p < arr + 5; p++) {
        printf("%d ", *p);
    }
    printf("\n");

    // 2. sum() with pointer arithmetic
    printf("sum = %d\n", sum(arr, 5));

    // 3. Add elements until reaching a 0
    int b[] = {4, 6, 7, 8, 9, 0};
    int total = 0;
    for (int *p = b; *p != 0; p++) {
        total += *p;
    }
    printf("total = %d\n", total);
    return 0;
}
```

Output:

```
4 6 7 8 9
sum = 34
total = 34
```
