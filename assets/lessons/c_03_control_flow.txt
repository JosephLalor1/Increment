@title Making Decisions and Loops

Programs become useful when they can choose between actions and repeat work. C gives you if/else for decisions and loops such as for and while for repetition.

# if and else

```
int temperature = 25;

if (temperature > 30) {
    printf("Hot\n");
} else if (temperature > 15) {
    printf("Warm\n");
} else {
    printf("Cold\n");
}
```

The condition inside the parentheses is checked from top to bottom. The first one that is true runs, and the rest are skipped.

> In C, zero counts as false and any non-zero value counts as true.

# Comparison operators

== tests equality, != tests inequality, and <, >, <=, >= compare sizes. Watch out: = assigns, == compares. Writing if (x = 5) is a classic bug.

# The for loop

A for loop has three parts: a starting step, a condition checked before each pass, and an update run after each pass.

```
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
// prints: 0 1 2 3 4
```

# The while loop

A while loop repeats as long as its condition stays true.

```
int n = 3;
while (n > 0) {
    printf("%d...\n", n);
    n--;
}
printf("Liftoff!\n");
```
