# Computer memory revisited

A computer stores data in memory slots, and every slot has a unique address. When you declare variables, each one lives at some address:

```
Addr   Content
1000   i: 37
1001   j: 46
1002   k: 58
1003   m: 74
1004   a[0]: 'a'
1005   a[1]: 'b'
1006   a[2]: 'c'
1007   a[3]: '\0'
1008   ptr: 1001
```

Changing a variable, for example i = 40;, changes the content stored at its address. Look at ptr at address 1008: its content is 1001, which is the address of j. That is what a pointer is.

# What a pointer is

A pointer is a variable that stores the address of another variable. It refers to a memory location rather than holding an ordinary value.

```
int i = 5;
int *ptr;    // declare a pointer to an int
ptr = &i;    // store the address of i in ptr
*ptr = 10;   // change the contents at the address in ptr
```

After this code, i is 10. ptr is NOT storing the value of i; it stores where i lives.

Step through it below. Click each line of code to run the program up to that line, and click any box to have it explained.


# The twin operators

- & is the address-of operator. &j gives the address of j, so ptr = &j; makes ptr point to j.
- * is the dereference operator. *ptr means "the contents of the address in ptr", so *ptr = 99; changes whatever ptr points to.

> The * appears in two places. In a declaration, int *ptr; means "ptr is a pointer to int". In an expression, *ptr means "the value ptr points to".

# Printing pointers

%p prints an address. Addresses differ from run to run, so your output will show a different number:

```
#include <stdio.h>

int main() {
    int i = 5;
    int *ptr = &i;
    printf("i = %d\n", i);
    printf("*ptr = %d\n", *ptr);
    printf("ptr = %p\n", (void *)ptr);  // address of i
    return 0;
}
```

Example output:

```
i = 5
*ptr = 5
ptr = 000000000061FE14
```

# An illustration

Follow the values line by line. One pointer can point at different variables over time.

```
#include <stdio.h>

int main() {
    int i = 5, j = 10;
    int *ptr;
    ptr = &i;     // ptr points to i
    *ptr = 3;     // i becomes 3
    ptr = &j;     // ptr now points to j
    *ptr = -2;    // j becomes -2
    printf("i = %d, j = %d\n", i, j);
    return 0;
}
```

Output:

```
i = 3, j = -2
```

Watch the arrow move as ptr is pointed first at i, then at j:

```memory

say Two ordinary ints, side by side in memory: i at 1000 and j at 1004 (an int takes 4 bytes).
> int *ptr;
var ptr int* ?
say ptr is declared but not set, so it holds garbage: a random address.

set ptr &i
say ptr now holds 1000, the address of i. The arrow shows that ptr points to i.
> *ptr = 3;     // i becomes 3
set *ptr 3
say *ptr = 3 follows the arrow and stores 3 at the end of it. ptr points to i, so i becomes 3.
> ptr = &j;     // ptr now points to j

say Assigning to ptr itself (no *) changes where it points. ptr now holds 1004, the address of j, and the arrow moves to j. i keeps its value 3.
> *ptr = -2;    // j becomes -2
set *ptr -2
say The same statement as before, *ptr = ..., now changes j, because ptr points to j. That is the point of pointers: one name, any variable.
```

# Initialise your pointers

A pointer declared without a value holds a random address. Dereferencing it writes to some unknown place in memory, which can crash the program or silently corrupt other data. When a pointer has nothing to point at yet, set it to NULL, and check for NULL before using it.

```
int *p = NULL;     // safe: clearly points at nothing
if (p != NULL) {
    *p = 50;       // only dereference a valid pointer
}
```
